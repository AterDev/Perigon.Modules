# 资源属性

当前的`ResDefinitionProperty`用来定义一个属性，但目前它是资源定义是一对多的关系。

实际很多属性是可以复用的，比如名称，描述，IP等，为避免重复定义，现在修改 `ResDefinitionProperty`与`ResDefinition`的关系为多对多，新增一个中间表`ResDefinitionPropertyMap`，用来关联资源定义和属性。

## 实施说明

### 接口说明

编写属性相关的接口，以提供对资源属性的增删改查功能。属性的增删改查接口需要考虑到属性的复用性，确保在删除属性时不会影响到其他资源定义的使用，被引用时，要提示用户该属性正在被使用，不能删除。


修改现有的新增(编辑)资源定义的接口，以变成多对多关系的数据处理。

### 前端实现

在资源定义组件中，即`resource/definition`，使用tab页的形式，添加一个`属性定义`，原来的叫资源定义，在属性定义中，实现属性的列表展示，编辑/修改弹窗功能。

然后在`资源定义`中，在新增定义和编辑定义的弹窗中，之前只一个新增属性的按钮，现在添加一个`选择属性`的按钮，点击后弹出一个选择已有属性的弹窗(展示属性名称和类型)，可以进行多选，选择后，像新增属性一样，在定义的弹窗中多出一条定义属性(因为是选择的，所以不可更改内容)。

### 其他

其他受影响的内容，也要一同修改，以保持业务逻辑的正确性。
